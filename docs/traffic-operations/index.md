# Traffic Operations

Working knowledge for day-to-day traffic operations — the stuff that should be reachable in under thirty seconds from a phone in the field.

!!! warning "Generic reference only"
    Nothing here is jurisdiction-specific advice. Always defer to the current edition of the **MUTCD**, state supplement, and local agency standard operating procedures.

## Sub-domains

- **Signals** — phasing, timing, detection, preemption, signal-head standards.
- **Incident management** — TIM roles, lane-closure tapers, quick-clearance rules.
- **Work zones** — temporary traffic control plans, device spacing, flagger procedures.
- **Data & ITS** — detector health, count programs, dashboards, communications.
- **Standards** — MUTCD references, agency-specific deviations, signing & marking.

## At-a-glance references

=== "Signal timing"

    | Parameter           | Typical range            |
    | ------------------- | ------------------------ |
    | Minimum green       | 4–7 s                    |
    | Pedestrian walk     | ≥ 7 s                    |
    | Ped clearance (FDW) | distance ÷ 3.5 ft/s      |
    | Yellow change       | 3.0–6.0 s                |
    | All-red clearance   | 0.5–2.0 s                |

=== "Work-zone tapers"

    | Posted speed | Merging taper length |
    | ------------ | -------------------- |
    | 25 mph       | L = WS²/60           |
    | 45 mph       | L = WS                |
    | 55+ mph      | L = WS                |

    Where `W` = lane offset (ft) and `S` = speed (mph).

## Incident response — first 10 minutes

1. **Confirm scene safety** before approaching.
2. **Establish command** — even informally; someone owns the scene.
3. **Protect the scene** — apparatus placement, lane closure upstream.
4. **Assess casualties** — call for EMS resources early.
5. **Notify partners** — TMC, law enforcement, towing.
6. **Start the clock** for quick clearance — every minute of closure compounds secondary-crash risk.

??? note "Why the 10-minute focus?"
    Studies consistently show secondary-crash probability rises roughly linearly with closure duration in the first 30 minutes. The first ten are where preventable damage accumulates fastest.

## Common references

- **MUTCD** — Manual on Uniform Traffic Control Devices (current FHWA edition).
- **HCM** — Highway Capacity Manual, for LOS and saturation flow calcs.
- **NCHRP Report 500 series** — strategy guides by crash type.
- **TIM Responder Training** — FHWA's National TIM Responder Training Program.
