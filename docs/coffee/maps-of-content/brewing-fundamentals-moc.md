# Brewing Fundamentals MOC

Coffee brewing is the process of extracting soluble compounds from roasted grounds using water, governed by a set of interrelated variables that collectively determine cup quality. This MOC organises the foundational science, key variables, methods, and troubleshooting knowledge needed to brew coffee consistently and well.
