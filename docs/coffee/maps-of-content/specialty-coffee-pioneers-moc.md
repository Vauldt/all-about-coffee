# Specialty Coffee Pioneers MOC

The specialty coffee movement was shaped by a relatively small number of individuals — roasters, baristas, graders, and entrepreneurs — whose decisions about sourcing, roasting, brewing, and communication redefined what coffee could be. This MOC collects the key figures of the movement: the founding generation who established quality as a priority, the roasters who built the pioneering businesses, and the competition champions whose public performances drove technique and culture forward. For the organisations these figures built, see [Specialty Coffee Institutions MOC](specialty-coffee-institutions-moc.md).

## Specialty Coffee Pioneers Overview

| Note | Description |
| :--- | :--- |

| [George Howell](../coffee-business/george-howell.md) | Coffee Connection 1975; Cup of Excellence co-founder 1999; direct trade pioneer |
| [James Hoffmann](../coffee-business/james-hoffmann.md) | 2007 WBC champion; Square Mile Coffee co-founder; leading public educator |
| [Tim Wendelboe](../coffee-business/tim-wendelboe.md) | 2004 WBC champion; Oslo roastery; defined Nordic ultra-light roasting |
| [Gwilym Davies](../coffee-business/gwilym-davies.md) | 2009 WBC champion; Prufrock Coffee, London |
| [Pete Licata](../coffee-business/pete-licata.md) | 2013 WBC champion; later Counter Culture Coffee director of coffee |
| [Sasa Sestic](../coffee-business/sasa-sestic.md) | 2015 WBC champion; ONA Coffee, Canberra; CO₂ carbonic maceration pioneer |
| [Agnieszka Rojewska](../coffee-business/agnieszka-rojewska.md) | 2018 WBC champion; first female WBC winner in the event's 18-year history |
| [Matt Perger](../coffee-business/matt-perger.md) | 2012 WBrC champion; Barista Hustle founder; EK43 co-discoverer |
| [Intelligentsia Coffee](../coffee-business/intelligentsia-coffee.md) | Chicago, 1995; formalised Direct Trade programme 2003 |
| [Counter Culture Coffee](../coffee-business/counter-culture-coffee.md) | Durham NC, 1995; annual Transparency Report; training centre model |
| [Stumptown Coffee](../coffee-business/stumptown-coffee.md) | Portland, 1999; Duane Sorenson; Hair Bender blend; quality-obsessed sourcing |
| [Blue Bottle Coffee](../coffee-business/blue-bottle-coffee.md) | Oakland, 2002; James Freeman; 48-hour freshness rule; Japanese aesthetic |
| [Square Mile Coffee](../coffee-business/square-mile-coffee.md) | London, 2008; James Hoffmann and Annette Moldvaer |
| [Heart Coffee Roasters](../coffee-business/heart-coffee-roasters.md) | Portland; precision roasting |
| [The Coffee Collective](../coffee-business/the-coffee-collective.md) | Copenhagen, 2007; Klaus Thomsen (2006 WBC); FOB price transparency |
| [Koppi Coffee](../coffee-business/koppi-coffee.md) | Sweden; ultra-light Nordic roasting |
| [Kaffa Roastery](../coffee-business/kaffa-roastery.md) | Helsinki; Finnish specialty pioneer |
