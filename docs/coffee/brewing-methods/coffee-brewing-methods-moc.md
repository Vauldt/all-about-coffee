# Coffee Brewing Methods MoC

This map of content covers all coffee brewing methods documented in Coffeepedia — from manual filter methods through espresso, immersion, and automated systems. It is the primary navigation hub for the brewing section of the encyclopedia. Each method article covers principles, equipment, recipe parameters, and troubleshooting.
