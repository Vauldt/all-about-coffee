## Overview

Coffeepedia organises its 40 Maps of Content (MOCs) into 10 subject domains spanning plant science, origin and geography, processing, roasting, brewing, extraction and chemistry, equipment, sensory science, coffee drinks, and professional development. Each MOC is a navigation hub linking to the data files within its domain. This note provides a complete directory of all MOCs, grouped by topic, together with suggested learning paths.

## How MOCs Connect

### The Core Learning Path

```
Coffee Origins → Processing → Roasting → Grinding → Extraction → Brewing
       ↓             ↓           ↓          ↓           ↓           ↓
   Geography    Methods    Profiles   Particle    Chemistry   Technique
```

### The Problem-Solving Path

```
Bad Coffee → Troubleshooting MOC → Identify Issue
                                         ↓
                                   Extraction?
                                    ↙         ↘
                          Grind Issue      Water Issue
                               ↓                ↓
                        Grinder MOCs      Water MOC
```

### The Deep Knowledge Path

```
Fundamentals → Chemistry → Detailed Science → Advanced Techniques
```
